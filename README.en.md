# HomeStock 家裡物品資料庫

一個給全家人一起使用的 iPhone App，用來記錄**家裡的東西放在哪裡**、**什麼時候過期**、**多久要用一次**，以及**什麼時候該補貨**


## 製作理念

家裡的東西常常有這些問題：

- 想找某樣東西，卻忘了收在哪個櫃子的哪一層
- 東西放到過期才發現，或是重複買了家裡已經有的
- 濾網、牙刷這類要定期更換的東西，總是忘記換
- 家人各自收東西，別人找不到

HomeStock 把這些事集中在一個 App 裡，整個操作只有兩件事：**登錄**和**查詢**

- **登錄**：把東西記下來，只有名稱是必填，其他都可以之後再補
- **查詢**：用搜尋、標籤或地圖找到東西在哪裡，並在該處理的時候收到提醒

畫面採用暗藍色加紫色的配色，地圖則用類似放置遊戲的網格地板，讓整理家裡這件事稍微有趣一點


## 功能大綱

### 物品
- 每個物品可以記錄：名稱、大分類、小標籤、品牌、位置、有效日期、使用週期、數量。除了名稱以外都可以空著
- 有效日期：到期前 N 天通知，N 每個物品可以自己設定
- 使用週期：每 N 天、週或月要使用或更換一次。按「已使用」後重新計時
- 數量：可以按 ＋／− 增減，降到設定的數量以下時提醒補貨
- 物品詳情頁可以編輯、刪除，也會顯示「快過期」、「該使用了」、「該補貨」等狀態

### 標籤
- **大分類**：每個物品最多一個，例如洗漱用品、衛生用品、電子用品；沒選就是「未分類」
- **小標籤**：可以自由組合多個，例如衛生紙、抹布
- **品牌**：每個物品一個
- 登錄時可以直接在同一個畫面點選或新增標籤。用過的標籤會自動記住，可以在「設定 › 標籤管理」刪除
- 標籤全家共用

### 查詢（主頁）
- 列出所有物品，可以用名稱、標籤或位置搜尋
- 上方可以快速切換大分類，也能用小標籤、品牌篩選
- 排序方式：最新登錄、名稱、最緊急
- 可以只看「需要處理的」物品，也就是快過期、該使用、該補貨的東西

### 位置
- 結構為：**房間 → 櫃子（層 × 欄的格子）→ 盒子**
- 櫃子可以自訂層數和欄數，例如 3 層 × 2 欄共 6 格
- 盒子可以放在櫃子的某一格，也可以直接放在房間裡
- 物品可以放在房間、櫃子的某一格或盒子裡
- 移動盒子時，裡面的物品會自動跟著走

### 網格地圖
- 每個房間一片網格地板，正上方 2D 視角，預設 10 × 8 格，可以調整大小
- **櫃子和傢俱**：佔格子，可以拖曳移動（會對齊格子、不能重疊），也能調整大小、旋轉 90° 或刪除
- **內建傢俱**：桌子、床、椅子
- **自訂傢俱**：可以自訂名稱、圖示和大小，存成樣板後全家都能重複使用
- **牆和門**：畫在格線上、不佔格子，可以圍出不是四方形的格局
- 點櫃子可以直接打開，看每一格放了什麼

### 家庭共用
- 一人建立家庭並設定密碼，系統會產生 6 碼家庭代碼，家人輸入代碼和密碼就能加入
- 每個房間可以設成**全家共用**或**私人**：私人房間和裡面的東西只有建立者看得到
- 家庭建立者可以移除成員、變更密碼
- 資料存在雲端，家人之間即時同步；沒有網路時也能使用，連線後會自動同步

### 通知
- 有效日期、使用週期、補貨三種提醒，都是 iPhone 本機通知，不需要另外架伺服器
- 可以在設定頁調整每天的通知時間，以及新物品預設提前幾天通知


## 技術架構

| 項目 | 使用的技術 |
|---|---|
| 平台 | iOS 17 以上（iPhone） |
| 語言／介面 | Swift、SwiftUI |
| 資料庫 | Firebase Cloud Firestore（含離線快取） |
| 登入 | Firebase Authentication 匿名登入，配合家庭代碼與密碼 |
| 權限控管 | Firestore 安全規則（`firestore.rules`） |
| 通知 | UserNotifications 本機通知 |
| 發佈方式 | 不上架 App Store，用 Xcode 直接安裝到自己的 iPhone |

## 尚未完成的功能

- **AI 拍照辨識**：拍商品照片，自動填入名稱與品牌；預計使用 Google Gemini API，金鑰由使用者在設定頁自行填入
- **牆和門的拖曳移動**：目前放錯位置只能刪除重畫
- **傢俱與牆的碰撞判斷**：目前傢俱可以擺在牆上，系統不會擋
- **牆外格子的處理**：牆外面的格子還是看得到，也能放東西
- **地圖格子大小**：手機上每格偏小，櫃子名稱不易閱讀
- **效能優化**：每次資料變動都會重新排程所有通知，資料多時可能會卡頓
- **補貨通知的範圍**：目前只有調整數量的那支手機會收到補貨通知，其他家人不會收到
- **舊資料搬移**：改用雲端資料庫之前存在手機裡的資料，沒有提供上傳功能


## 使用方式

### 一、開發環境需求

- Mac，並安裝新版 Xcode（要能支援手機的 iOS 版本，例如 iOS 26 的手機需要 Xcode 26 以上）
- iPhone（iOS 17 以上）與傳輸線
- Apple ID（免費帳號即可）
- Google 帳號（用來建立 Firebase 專案）

### 二、建立 Firebase 專案

這個 repo **不包含** `GoogleService-Info.plist`，要自己建立 Firebase 專案並下載

1. 到 [Firebase 控制台](https://console.firebase.google.com) 建立專案，使用免費的 Spark 方案即可
2. 「新增應用程式」→ 選 **iOS**，Apple 軟體包 ID 填 Xcode 專案的 Bundle Identifier
3. 下載 `GoogleService-Info.plist`，放進 Xcode 專案的 `HomeStock` 資料夾
4. **Authentication** → 登入方式 → 啟用 **匿名**
5. **Firestore Database** → 建立資料庫（建議位置選 `asia-east1`，模式選正式版）
6. Firestore 的 **規則** 分頁：貼上本專案的 `firestore.rules` 並發布

### 三、用 Xcode 安裝到 iPhone

1. 用 Xcode 開啟 `HomeStock.xcodeproj`
2. 如果 Firebase 套件沒有自動載入：File → Add Package Dependencies → 輸入 `https://github.com/firebase/firebase-ios-sdk`，只加入 **FirebaseAuth** 和 **FirebaseFirestore**
3. TARGETS HomeStock → **Signing & Capabilities** → Team 選自己的 Apple ID
4. iPhone 用傳輸線接上 Mac，上方的裝置選單選你的 iPhone，按 ▶ 執行
5. 第一次安裝時，在 iPhone 上做兩件事：
   - 設定 › 隱私權與安全性 › 打開**開發者模式**（手機會重開機）
   - 設定 › 一般 › VPN 與裝置管理 › 信任自己的開發者 App

> **注意**：免費 Apple ID 簽署的 App 每 **7 天**要重新簽一次。到期時 App 會打不開，只要接上 Mac 再按一次 ▶ 就恢復，資料不會消失
> 在 Xcode 的 Window › Devices and Simulators 勾選 **Connect via network** 後，只要 Mac 和手機在同一個 Wi-Fi，就可以不用接線重新安裝
>
> **不要從手機上刪除 App**：刪除後要重新用代碼和密碼加入家庭，而且那支手機原本建立的私人房間會再也看不到

### 四、第一次開啟

- **第一個人**：選「建立家庭」，輸入家庭名稱、自己的暱稱和密碼。完成後會顯示 6 碼的**家庭代碼**
- **其他家人**：選「加入家庭」，輸入家庭代碼、密碼和自己的暱稱
- 允許通知權限，才收得到提醒
- 家庭代碼之後可以在「設定 › 家庭」查看

### 五、日常使用

1. **建立位置**：到「位置」分頁新增房間（選擇全家共用或私人），再新增櫃子並設定層數和欄數，需要的話在格子裡新增盒子
2. **擺放地圖**：到「地圖」分頁按「編輯」，用 ＋ 加入傢俱，拖曳擺好櫃子；切換到「畫牆」、「放門」工具畫出房間的格局
3. **登錄物品**：到「登錄」分頁輸入名稱，點選標籤、選擇位置，視需要設定有效日期、使用週期和數量，按「儲存」
4. **查詢物品**：在「查詢」分頁搜尋或篩選；或在「地圖」分頁點櫃子，看每一格放了什麼
5. **處理提醒**：
   - 用過需要定期更換的東西，到物品詳情按「**已使用**」重新計時
   - 用掉東西時按 **−** 扣數量，快用完時會提醒補貨
6. **調整設定**：「設定」分頁可以調整通知時間、管理標籤和家庭成員
